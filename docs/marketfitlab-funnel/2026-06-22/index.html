7. Validation & Caveats

샘플 크기: 폼 시작 5건·이탈 5건의 소표본. 필드별 이탈 패턴(form_solutions 60%)을 확정 사실로 보기 어렵고 방향성 가설로 활용 권장. 4~6주 누적 시 신뢰도 강화.

폼 완료율 0% 해석: 전주 100%(2명)도 소표본이었기에, 이번 주 0%(5명)가 "구조적 악화"인지 "표본 변동"인지는 추가 관찰 필요. 단, form_solutions 초반 이탈 패턴은 반복 시그널로 취급할 것.

이벤트 네이밍 불일치: 작업 지시의 form_start / form_field_blur / form_error / form_abandon은 실제 미추적. GTM 실제 이벤트 start/abandon/error_demo_request 기준 분석.

form_field_blur 부재: 필드 단계별 통과율 정밀 추적 불가. last_field_touched 속성으로 우회 중. 정밀 분석을 위해 field_blur 이벤트 추가 태깅 권고.

CTA 중복 측정 가능성: click_to_demo_request와 articul8_click_demo_request가 동일 사용자 이중계측일 가능성. 분리 검증 P2 유지.
