Form abandonment diagnosis

  • Fact: 방문은 보합권이었고, 블로그 조회율은 약 42%로 개선되었습니다.
  • Fact: 주요 데모 CTA 클릭은 40+건이며 전주 50+ 대비 감소했습니다.
  • Fact: 폼 시작, abandon, error, submit 단계는 소표본이므로 공개본에서 상세 count와 비율을 마스킹합니다.
  • Hypothesis: 콘텐츠 관심은 유지되고 있으나 CTA 후 폼 진입 설득, 폼 입력 부담, 제출 성공 피드백 중 하나가 병목일 가능성이 있습니다.
  • Limit: 본 공개본은 집계 이벤트만 사용했고, 사용자 단위 원문과 개인 식별 가능 데이터는 조회하지 않았습니다.

Recommended actions

P0 CTA 클릭 후 폼 시작 전환을 우선 개선해야 합니다. 데모 요청 버튼 주변에 “받게 되는 산출물”, “상담 소요 시간”, “응답 방식”을 한 화면에서 명확히 제시하는 것을 권장합니다.
P1 폼 이벤트 QA를 진행해야 합니다. abandon 이벤트가 페이지 이탈, validation 실패, 제출 성공 후 중복 발화와 섞이지 않는지 확인해야 합니다.
P2 Articul8 CTA와 일반 데모 CTA를 랜딩 문맥별로 분리 모니터링해야 합니다. 다음 주에는 CTA source/page 섹션별 전환율을 추가 집계하는 것을 권장합니다.

Validation & Caveats

  • Mixpanel MCP 집계 이벤트를 기준으로 작성했습니다. 개인 식별 가능 데이터와 사용자 단위 원문은 포함하지 않았습니다.
  • 이번 공개본은 집계 이벤트 기준으로 제한 작성했으며, 추가 검증 소스는 내부 운영본에서 별도 관리합니다.
  • CTA total은 주요 데모 CTA 클릭 이벤트 2종을 합산한 값입니다. 동일 사용자의 중복 클릭 가능성은 추가 점검 대상입니다.
  • 폼 단계 표본이 작아 전환 개선이나 악화를 단정하지 않습니다. 다음 2주 누적 추세로 내구성을 확인해야 합니다.
  • 전주 리포트의 방문, 블로그, CTA 수치는 공개본의 반올림 또는 범위 표기에서 추출했습니다. 폼 시작과 제출의 전주 수치는 자동 추출이 제한됩니다.
