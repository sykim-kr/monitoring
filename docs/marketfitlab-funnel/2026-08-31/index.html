Form abandonment diagnosis

  • Fact: 방문은 전주 대비 약 10% 감소했지만 블로그 소비율은 ~39%로 개선되었습니다.
  • Fact: 주요 데모 CTA 클릭은 50+건이며 전주 대비 약 25% 감소했습니다.
  • Fact: 폼 시작, abandon, error, submit 단계는 소표본이므로 공개본에서 상세 count와 비율을 마스킹합니다.
  • Hypothesis: 콘텐츠 관심은 유지되고 있으나 CTA 후 폼 진입 설득, 폼 입력 부담, 제출 성공 피드백 중 하나가 병목일 가능성이 있습니다.
  • Limit: 본 공개본은 집계 이벤트만 사용했고, 사용자 단위 원문과 개인 식별 가능 데이터는 조회하지 않았습니다.

Recommended actions

P0 CTA 클릭 후 폼 시작 전환을 우선 개선해야 합니다. CTA 도착 화면의 첫 문장, 데모 요청 가치 제안, 폼 진입 버튼의 기대 결과를 한 화면에서 명확히 제시하는 것을 권장합니다.
P1 폼 submit 이벤트와 abandon 이벤트 발화 조건을 QA해야 합니다. 성공 페이지 진입, 네트워크 오류, 필수 필드 오류가 각각 다른 이벤트로 기록되는지 확인해야 합니다.
P2 CTA 랜딩 문맥을 별도 세그먼트로 모니터링해야 합니다. 다음 주에는 CTA 이후 폼 단계의 2주 누적 추세를 함께 추적하는 것을 권장합니다.

Validation & Caveats

  • 본 공개본은 집계 이벤트 기준입니다. 개인 식별 가능 데이터와 사용자 단위 원문은 포함하지 않습니다.
  • 추가 데이터 소스 교차검증은 별도 내부 검토 범위입니다.
  • CTA total은 주요 데모 CTA 클릭 이벤트 2종을 합산한 값입니다. 동일 사용자의 중복 클릭 가능성은 추가 점검 대상입니다.
  • 폼 단계 표본이 작아 전환율을 성과 개선으로 단정하지 않습니다. 다음 2주 누적 추세로 내구성을 확인해야 합니다.
