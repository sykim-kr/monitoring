Form abandonment diagnosis

  • 확인된 사실: 페이지뷰는 2,126건, 블로그 조회는 616건, 주요 데모 CTA 클릭은 177건입니다.
  • 확인된 사실: CTA 클릭에서 폼 시작까지의 전환율은 7.3%이며, 시작 후 이탈률은 76.9%입니다.
  • 확인된 사실: 오류 이벤트와 제출 이벤트는 소표본 보호 기준에 해당하므로 공개본에서는 상세 수치를 보호합니다.
  • 가설: CTA 클릭 대비 폼 완료가 낮아 CTA 이후 이동, 폼 로딩, 필드 입력 마찰, 이벤트 발화 조건을 먼저 점검하는 것이 좋습니다.
  • 한계: 본 공개본은 집계 이벤트만 사용했으며 개인 식별 가능 데이터, 사용자 단위 원문, 프로필 데이터는 조회하지 않았습니다.

Recommended actions

P0 CTA 클릭 후 폼 노출까지의 실제 경로를 QA하고, 폼 시작 이벤트가 모든 CTA 랜딩에서 동일하게 발화되는지 확인하는 것을 권장합니다.
P1 폼 시작 후 이탈률이 높으므로 첫 입력 필드, 필수 입력 수, 제출 버튼 활성화 조건, 오류 메시지 노출을 점검해야 합니다.
P2 블로그 조회 수는 늘었지만 조회율은 소폭 하락했으므로, 유입 페이지별 블로그 유도 문구와 내부 링크 위치를 함께 점검하는 것을 권장합니다.

Validation & Caveats

  • 본 공개 리포트는 Mixpanel 집계 이벤트를 기준으로 작성했습니다. 추가 검증 소스는 내부 검토 범위에서 별도로 관리합니다.
  • BigQuery 검증은 이번 공개본의 범위에 포함하지 않았습니다.
  • CTA total은 주요 데모 CTA 2종을 합산했습니다. 동일 사용자의 중복 클릭 가능성은 남아 있습니다.
  • 폼 제출은 소표본이므로 전환율 개선 또는 악화를 단정하지 않습니다. 2주 이상 누적 추세로 내구성을 확인해야 합니다.
  • 전주 비교는 공개 리포트의 집계 수치에서 추출했습니다. 전주 공개본에서는 동일 기준의 상세 수치를 제공하지 않아 직접 비교를 제한합니다.
