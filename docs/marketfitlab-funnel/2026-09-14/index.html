Form abandonment diagnosis

  • Fact: 페이지뷰는 1,446건, 블로그 조회는 632건, 주요 데모 CTA 클릭은 16건입니다.

  • Hypothesis: 이번 주 관측 기준으로는 폼 내부 오류보다 블로그 또는 랜딩 콘텐츠에서 데모 CTA로 이어지는 문맥을 먼저 점검할 필요가 있습니다.
  • Limit: 본 공개본은 집계 이벤트만 사용했으며 개인 식별 가능 데이터, 사용자 단위 원문, 프로필 데이터는 조회하지 않았습니다.

Recommended actions

P0 데모 CTA 직전 문구를 “분석 진단에서 받는 산출물, 소요 시간, 후속 제안 방식” 중심으로 바꾸는 것을 권장합니다. 다음 주에는 CTA 클릭률 회복을 1차 성공 기준으로 확인해야 합니다.
P1 블로그 상단과 본문 중간 CTA를 분리 태깅해야 합니다. 어떤 문맥의 CTA가 폼 시작으로 이어지는지 확인해야 합니다.
P2 폼 이벤트 QA를 유지해야 합니다. abandon 이벤트가 단순 페이지 이탈, validation 실패, 제출 성공 후 중복 발화와 섞이지 않는지 확인해야 합니다.

Validation & Caveats

  • Mixpanel MCP 집계 이벤트를 기준으로 작성했습니다. GA4는 numeric propertyId 및 권한이 확인되지 않아 사용하지 않았습니다.
  • BigQuery는 MarketFit Lab과 직접 연결된 테이블을 이번 bounded run에서 확인하지 않아 사용하지 않았습니다.
  • CTA total은 click_to_demo_request와 articul8_click_demo_request를 합산했습니다. 동일 사용자의 중복 클릭 가능성은 남아 있습니다.
  • 폼 단계는 표본이 작으므로 전환율 개선 또는 악화를 단정하지 않습니다. 다음 2주 누적 추세로 내구성을 확인해야 합니다.
  • 전주 비교는 공개 리포트의 반올림 또는 범위 표기에서 추출했습니다. 폼 시작과 제출의 전주 수치는 자동 추출이 제한됩니다.
