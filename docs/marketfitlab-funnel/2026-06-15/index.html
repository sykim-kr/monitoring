📌 Executive Summary

이번 주 1,776명이 방문(전주 대비 +16.3%)하고 827명이 블로그를 읽었습니다(전환율 46.6%, 전주 59.7%→46.6%로 하락). 반면 데모 제출은 4건 → 2건으로 -50% 감소했고, 폼 행동 추적 결과 CTA 클릭 48회 중 폼 진입은 단 2명(4.2%)에 그쳤습니다. 지난 주 P0 액션(폼 단계 분리·필드 최소화)이 아직 반영되지 않은 상태이며, 이탈 필드 패턴은 지난 주와 동일 — Privacy와 form_solutions 두 지점이 다시 병목으로 확인됐습니다. 폼 진입 자체가 더 줄어든 것이 이번 주의 가장 큰 변화입니다.

6. 추천 액션 (지난 주 P0 후속 상황 포함)

우선순위액션지난 주 대비
P0 지난 주 P0 액션 반영 상태 확인 — 폼 단계 분리(이름+이메일→나머지) & 폼 필드 최소화(전화번호 선택사항·회사명 자동완성)가 적용됐는지 점검 지표는 미반영을 시사 (폼 진입율 더 하락)
P0 Privacy 필드 UX 긴급 개선 — 2주 연속 마지막 이탈 지점. 위치를 제출 버튼 바로 위로 이동, 체크박스 강조, 동의 문구 1줄로 단축 P1 → P0 격상
P0 form_solutions UI 개선 — 선택지 단순화, "잘 모르겠음/상담 후 결정" 옵션 추가. 6필드 채운 사람이 여기서 포기하는 것을 막아야 함 P1 → P0 격상
P1 CTA → 폼 페이지 마찰점 진단 — CTA 48회 중 46회가 폼 시작도 안 함. CTA 도착 후 폼 페이지 로딩 속도·즉시 가시성·페이지 이동 여부 점검 (세션 리플레이 권장) 신규 P1 (전주 P0 폼단계분리와 연결)
P1 이벤트 네이밍 정합성 정리 — GTM 실제 이벤트(start/abandon/error_demo_request)와 작업 지시 문서의 네이밍(form_*)이 다름. 표준 1개로 통일 + form_field_blur는 현재 미수집 → 추가 태깅 필요 신규 P1
P2 articul8 vs 일반 CTA 분리 분석 — articul8 클릭 32회가 동일 사용자 이중계측인지, 다른 페이지 유입인지 확인. 진짜 클릭자 수 검증 전주 동일
P2 Exit Intent 미니 폼 — 폼 페이지 이탈 시도 시 "이메일만 남기기" 미니 폼 노출 전주 동일 유지

7. Validation & Caveats

샘플 크기: 폼 시작 2건·이탈 2건의 매우 작은 표본. 필드별 이탈 1:1 분포를 일반화하기 어려움. 4~6주 누적 시 의미 강화.
이벤트 네이밍: 작업 지시의 form_start / form_field_blur / form_error / form_abandon은 실제 추적되지 않음. 본 리포트는 GTM에 실제 배포된 start/abandon/error_demo_request 기준 작성.
form_field_blur 부재: 필드별 통과율(어느 필드까지 갔는지) 추적이 현재 불가능. last_field_touched 속성으로 우회 분석 중. 정밀 분석을 위해 field_blur형 이벤트 추가 권고.
CTA 중복 가능성: click_to_demo_request와 articul8_click_demo_request가 동일 사용자 이중계측 가능성. 분리 검증 P2 액션으로 누적.
전주 비교 기준: 이번 주 KPI 카드의 트렌드는 직전 7일(2026-06-01~07) 동일 정의 기준. 정성·외부 변수(콘텐츠 발행·캠페인) 미반영.
개인정보: 본 리포트는 개인 식별 데이터를 포함하지 않습니다 (집계 지표·필드 이름만 노출).
