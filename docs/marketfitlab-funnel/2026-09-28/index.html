Form abandonment diagnosis

  • Fact: 페이지뷰는 1,283건, 블로그 조회는 387건, 주요 데모 CTA 클릭은 113건입니다.
  • Fact: CTA 클릭은 주요 CTA 2종 합산 기준이며, 공개본에서는 내부 이벤트명 상세를 축소했습니다.
  • Fact: 데모 폼 시작, 이탈, 오류, 제출은 모두 소표본 보호 기준에 해당합니다.
  • Hypothesis: CTA 클릭 회복 대비 폼 단계 표본이 작아 CTA 이후 이동, 랜딩 문맥, 폼 로딩 또는 이벤트 발화 조건을 먼저 점검하는 것이 좋습니다.
  • Limit: 본 공개본은 집계 이벤트만 사용했으며 개인 식별 가능 데이터, 사용자 단위 원문, 프로필 데이터는 조회하지 않았습니다.

Recommended actions

P0 주요 CTA 클릭 후 실제 폼 노출까지의 이동 경로를 QA하고, 클릭 이벤트와 폼 시작 이벤트의 연결 조건을 확인하는 것을 권장합니다.
P1 폼 단계 소표본 신호가 특정 날짜에 집중되어 있어 해당 날짜의 배포, 유입 경로, 폼 로딩 로그를 함께 확인해야 합니다.
P2 블로그 조회율이 전주 53.0%에서 30.2%로 낮아졌으므로, 유입 페이지별 블로그 유도 문구와 내부 링크 위치를 재점검하는 것을 권장합니다.

Validation & Caveats

  • 본 공개본은 집계 이벤트 기준으로 제한 작성했습니다. GA4는 not used: propertyId/permission not confirmed 상태입니다.
  • BigQuery는 이번 공개본 범위에서는 사용하지 않았습니다.
