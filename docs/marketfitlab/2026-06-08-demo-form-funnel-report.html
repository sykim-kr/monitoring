4. 핵심 인사이트

52회 클릭 중 43명이 첫 필드조차 건드리지 않았습니다. 폼 페이지 첫인상에서 "복잡하다"고 느끼는 진입 장벽 문제로 추정됩니다.
2개
솔루션 선택 · 개인정보동의 반복 병목
이탈과 오류 모두에서 같은 필드가 등장합니다. 솔루션 선택지가 불명확하거나, 개인정보동의 체크박스가 눈에 잘 안 띄는 것으로 추정됩니다.

폼 시작 후 완료율은 양호
일단 첫 필드에 손을 댄 9명 중 4명이 완료했습니다. 폼 내부보다 폼 진입을 유도하는 것이 더 시급합니다.
토요일
주말 트래픽 집중, 전환은 평일
토요일에 방문(308명)·CTA 클릭(10회)이 최고치였지만 폼 시작은 1건, 제출은 0건. 주말 방문자는 즉시 전환 의도가 낮습니다.

5. 추천 액션

우선순위액션예상 효과
P0 폼 단계 분리 — 1단계: 이름+이메일만 → 2단계: 나머지 정보 수집 첫 진입 장벽 낮춰 폼 시작율 개선
P0 폼 필드 최소화 — 전화번호 선택 사항 변경, 회사명 자동완성 추가 이탈율 감소
P1 솔루션 선택 UI 개선 — 각 선택지에 설명 추가 또는 "상담 후 결정" 옵션 추가 솔루션 선택 단계 이탈·오류 감소
P1 개인정보동의 가시성 개선 — 필드 바로 아래 위치 이동, 필수 표시 강화 Privacy 관련 오류·이탈 감소
P2 주말 방문자 리타겟팅 — 토요일 방문 후 미전환자 대상 월요일 재노출 주말 트래픽 활용
P2 Exit Intent 팝업 — 폼 페이지 이탈 시도 감지 → "이메일만 남기기" 미니 폼 폼 미터치 이탈 일부 구제

집계 방식: 이벤트 발생 건수 기준. 동일 사용자의 여러 번 시도가 포함될 수 있음
